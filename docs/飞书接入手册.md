# 飞书机器人接入手册

> 目标：在手机飞书里私聊机器人，或把机器人拉进群 @ 它，查询公司/个人电脑上的本地知识库。
>
> 前提：机器人进程必须运行在**存放文件的那台电脑**上；电脑要开机、联网、不休眠。手机只是入口。

## 一、创建飞书自建应用

1. 打开飞书开放平台：<https://open.feishu.cn/app>
2. 创建「企业自建应用」，填写名称和描述。
3. 添加应用能力 → **机器人**。
4. 权限管理，至少勾选：
   - `im:message`：接收消息
   - `im:message:send_as_bot`：以应用身份发消息
   - `im:message.p2p_msg:readonly`：私聊消息
   - `im:message.group_at_msg:readonly`：群聊 @ 消息
   - 文件上传/发送相关权限（按开放平台“上传文件”“发送文件”接口的权限说明勾选）
5. 事件订阅：
   - 选择「长连接」方式
   - 订阅 `im.message.receive_v1`
6. 发布应用，提交管理员审核。
7. 审核通过后，在「凭证与基础信息」里拿 **App ID** 和 **App Secret**。

> 长连接方式不需要公网 IP、域名、SSL，也不需要在公司防火墙开入站端口。
> 但电脑必须能出站访问 `open.feishu.cn` 的 HTTPS/WSS 443。

## 二、安装与配置

```bash
cd personal-kb
KB_WITH_FEISHU=1 bash install.sh
```

Windows：

```powershell
$env:KB_WITH_FEISHU="1"
powershell -ExecutionPolicy Bypass -File install.ps1
```

编辑 `config/feishu.json`：

```json
{
  "app_id": "cli_xxx",
  "app_secret": "xxx",
  "allow_all": false,
  "allowed_open_ids": ["ou_你的open_id"],
  "allowed_chat_ids": []
}
```

- `allow_all` 默认 `false`；建议先把自己的 `open_id` 加进白名单。
- 不知道 `open_id` 时：临时设 `allow_all: true`，启动机器人后私聊发送 `/whoami`，它会回复 `open_id` 和 `chat_id`；填进白名单后把 `allow_all` 改回 `false`。
- `allowed_chat_ids` 用于限制允许使用的群；不填则只按用户白名单判断。

## 三、启动

```bash
kb feishu
```

或同时启动控制台、MCP、监听和机器人：

```bash
kb start --with-feishu
```

第一次运行 `kb feishu` 时，如果没有配置过索引范围，会自动弹出文件夹/盘符选择菜单，不需要单独先跑 `kb scope`。

启动成功会显示“飞书机器人已启动，等待消息”。

关闭：
- 终端按 `Ctrl+C`；
- 或如果使用 `kb start --with-feishu`，在本地控制台点「关闭服务」，会一起停止飞书机器人；
- 或另开终端运行 `kb stop`。

## 四、手机飞书使用

私聊机器人，或把它拉进群后 @ 它：

```text
找 报价单
发我 报销流程
总结 D:\项目A
整理 D:\发票
确认整理 <计划ID>
撤销 <计划ID>
状态
报销流程是什么
/whoami
```

- 「找」只返回文件列表和路径。
- 「发我」在只匹配到一个文件时，直接把文件发到聊天里。
- 「整理」只生成计划，不会立刻移动；确认后才执行。
- 群聊里只有 @ 机器人时才会响应。

## 五、网络与运行要求

| 项 | 要求 |
|---|---|
| 电脑状态 | 开机、联网、不休眠；锁屏可以 |
| 出站网络 | 能访问 `open.feishu.cn` 的 HTTPS/WSS 443 |
| 代理 | 公司代理需要设置 `HTTPS_PROXY` / `HTTP_PROXY` |
| 入站端口 | 不需要 |
| 权限 | 能读取你要索引的文件夹 |
| 飞书 | 自建应用已发布，机器人已加入会话 |

如果电脑关机、睡眠、断网，机器人就离线，手机端收不到回复。

## 六、排错

| 现象 | 处理 |
|---|---|
| `kb feishu` 提示配置为空 | 编辑 `config/feishu.json`，填 App ID/Secret |
| 提示缺少 lark-oapi | `KB_WITH_FEISHU=1 bash install.sh` 或 `pip install -e ".[feishu]"` |
| 长连接连不上 | 检查出站 443/WSS、代理、DNS；`kb doctor --feishu` |
| 机器人不回复 | 看终端日志；确认应用已发布、事件订阅是长连接、已订阅 `im.message.receive_v1` |
| 提示未授权 | 把 `open_id` 加进 `allowed_open_ids`，或临时 `allow_all: true` |
| 群聊不回复 | 必须 @ 机器人；确认机器人已进群 |
| 发文件失败 | 检查文件是否超过 30MB、应用是否有文件接口权限 |
| 电脑睡眠后不回复 | 电源设置改为“插电不休眠”；macOS 可用 `caffeinate` |

## 七、安全与合规

- 机器人只响应白名单用户/群；默认不是所有人可用。
- 日志不记录消息正文；引用只显示文件标题和路径。
- 文件内容会通过飞书消息发送，属于公司数据外发；使用前确认公司合规要求。
- 不要把 `app_secret`、`config/feishu.json` 提交到代码仓库或发给别人。
- 分享包用 `kb export --mode share`，不会包含 `config/feishu.json` 和 `data/`。
