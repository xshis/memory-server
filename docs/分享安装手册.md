# personal-kb 安装手册

## 一、打开分享网址下载

1. 浏览器打开分享方给的地址（形如 `http://192.168.15.16:8899/`）。
2. 按操作系统点击对应下载：
   - Windows：`personal-kb-share-win.zip`（约 212MB）
   - macOS：`personal-kb-share-mac.zip`（约 239MB）

   两个包都内置了本平台的依赖 wheel 和精确版本锁，安装时不用联网下载。
3. 解压到任意位置，得到 `personal-kb` 文件夹。

## 二、放模型缓存（30 秒，跳过下载）

| 系统 | 操作 |
|---|---|
| macOS / Linux | 终端执行：`cp -R fastembed_cache ~/.cache/fastembed` |
| Windows | 把 `fastembed_cache` 里的内容复制到 `C:\Users\你的用户名\.cache\fastembed` |

## 三、安装

**macOS**
1. 双击文件夹里的 `一键安装.command`（提示安全性：右键 → 打开）。
2. 问"是否安装本地模型"时，**选 4 跳过**（找文件不需要；以后要离线问答再装）。
3. 安装完终端执行：`source .venv/bin/activate`。

**Windows**
1. 右键 `一键安装.bat` → 以管理员身份运行。
2. 同样选 4 跳过本地模型。

**Linux / 鸿蒙**：终端执行 `bash install.sh`，模型选项选 4。

> 安装失败多为网络访问不了 PyPI，换网络或配 pip 镜像后重跑 `bash install.sh`。

## 四、启动并建索引

```bash
kb init          # 第一次会弹窗，选要索引的文件夹
kb index         # 建索引（文件多的等几分钟）
kb start         # 启动服务
kb map --open    # 自动打开 3D 脑图
```

macOS 如果选文件夹时看不到"桌面/文稿"内容：系统设置 → 隐私与安全性 → 完全磁盘访问 → 给终端打勾 → 重启终端重跑。

## 五、验收

浏览器出现 3D 星球图、顶栏有统计数字，即成功。

## 必须知道的两件事

1. **本机有代理（ClashX/Surge 等）**：给 127.0.0.1 加绕过规则，否则浏览器打不开脑图。
2. **首次打开脑图要等 1~2 分钟**（进度条走完），之后秒开。

更多功能（搜索/问答/整理/清理/飞书接入）见包内 `docs/安装与使用.md`。
