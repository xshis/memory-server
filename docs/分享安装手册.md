# personal-kb 安装手册（内网分享版）

> 适用对象：从局域网分享页下载安装包的用户。
> 阅读时间：5 分钟。遇到问题先看第 8 节"注意事项"，再翻压缩包内 `docs/安装与使用.md`（完整版）。

---

## 1. 支持系统

| 系统 | 支持 | 说明 |
|---|---|---|
| macOS 12+ | ✅ 全功能 | 菜单栏托盘仅 macOS 可用；完全磁盘访问需手动授权 |
| Windows 10/11 x64 | ✅ | PowerShell 执行策略需临时放宽（安装命令已含） |
| Linux（带 Python 的发行版） | ✅ | 无菜单栏托盘；命令行管理 |
| 鸿蒙 OS | ⚠️ 部分 | 需先有可用的 Python 3.10+ 终端环境；纯鸿蒙环境暂不支持 |

**硬件要求**：最低 8GB 内存 + 10GB 空闲磁盘；推荐 16GB + SSD。
**软件要求**：Python 3.10+（推荐 3.12）。没有 Python 时：macOS `brew install python@3.12`；Windows 去 python.org 安装并勾选"Add to PATH"。

---

## 2. 下载与校验

1. 浏览器打开分享地址（由分享方提供，形如 `http://192.168.x.x:8899/`）。
2. 点击下载 `personal-kb-share.zip`（约 105MB，含预置模型缓存）。
3. （可选）校验完整性：分享页显示 SHA256，终端执行
   `shasum -a 256 personal-kb-share.zip`（macOS/Linux）或
   `certutil -hashfile personal-kb-share.zip SHA256`（Windows），前 8 位一致即可。

> 包内**不含**索引、日志、真实配置、备份和分享方的任何个人文件。

## 3. 解压后第 0 步：放模型缓存（重要，可省 100MB 下载）

```
macOS/Linux:  cp -R fastembed_cache ~/.cache/fastembed
Windows:      把 fastembed_cache 文件夹里的内容复制到 %USERPROFILE%\.cache\fastembed
```

不做这步也能用——首次建索引时会自动联网下载模型（走 HuggingFace，不通自动走镜像；仍不通设 `HF_ENDPOINT=https://hf-mirror.com`）。

## 4. 安装

### macOS
```bash
cd personal-kb          # 解压出来的目录
bash install.sh         # 或双击 一键安装.command
source .venv/bin/activate
```
安装脚本结尾会询问是否装本地对话模型：演示/体验选 **4（不安装）**；要离线问答选 1（qwen2.5:3b，约 1.9GB）。跳过以后随时 `kb model install --name qwen2.5:3b` 补装。

### Windows（管理员 PowerShell）
```powershell
cd personal-kb
powershell -ExecutionPolicy Bypass -File install.ps1   # 或双击 一键安装.bat
.\.venv\Scripts\Activate.ps1
```

### Linux / 鸿蒙
```bash
cd personal-kb
bash install.sh
source .venv/bin/activate
```

**安装失败先看**：网络能否访问 PyPI（公司网配代理或镜像）；Python 版本是否 ≥3.10。重跑 `bash install.sh` 即可，幂等。

## 5. 首次启动与建索引

```bash
kb init      # 首次会弹窗选择要索引的文件夹（范围）
kb index     # 建索引 + 自动语义向量（全自动，无需再操作）
kb start     # 启动 3D 脑图 + MCP + 后台监听
kb map --open   # 打开 http://127.0.0.1:8770/
```

macOS 若被系统拦截：系统设置 → 隐私与安全性 → 完全磁盘访问 → 给终端打勾 → 重启终端重跑。

## 6. 验证安装成功

- 浏览器打开 http://127.0.0.1:8770/ 能看到 3D 星球脑图；
- 顶栏状态栏有统计数字与"语义嵌入 %"（建索引后自动补算，分批到 100%）；
- 右上角搜索框输入文件名，命中节点会亮起、非匹配淡出。

## 7. 日常使用速查

| 需求 | 命令/入口 |
|---|---|
| 找文件 | 脑图右上角搜索框 或 `kb search "关键词"`（语义混合检索） |
| 问资料 | 脑图左侧助手 或 `kb ask "问题"`（未装模型为摘录式回答） |
| 命令面板 | 脑图里 `Ctrl/⌘+P` |
| 看相似文件 | 点文件节点 → 档案卡"语义相似 top5" |
| 整理文件夹 | 顶栏"整理"（先出计划再执行，可撤销） |
| 清理重复/空文件 | 顶栏"清理空间"（移到废纸篓，可恢复） |
| 接入飞书/豆包 | `kb setup` 按引导（详见 docs/飞书接入手册.md） |

## 8. 注意事项

1. **本机代理必须放行 127.0.0.1**：装了 ClashX/Surge 等，给回环地址加绕过规则。症状：浏览器打不开脑图、MCP 客户端连不上，但终端 curl 正常。
2. **首次启动建图 1~2 分钟是正常的**：进度条显示真实百分比，不是卡死；建完秒开。
3. **语义向量全自动**：新文件入库后自动补算（限 2 核、两次间隔 ≥15 分钟），顶栏看进度；不需要语义检索可在安装时 `KB_WITH_EMBED=0`。
4. **资源占用**：索引大目录（几万文件）后数据库会到数 GB，属正常；`kb status` 看规模。建议 SSD 机器使用。
5. **机器发烫排查**：`ps -Ao pid,pcpu,command -r | head` 找占 CPU 的进程；不用的 AI 客户端窗口随手关。
6. **端口**：脑图 8770、MCP 8766，只监听本机；端口冲突时 `kb stop --force` 或改 `config/config.json`。
7. **权限**：macOS 索引"桌面/文稿/下载"需完全磁盘访问；服务不要用 sudo 运行。
8. **移动目录**：整个文件夹可拷贝移动，但移动后删掉 `.venv` 重跑 `bash install.sh`（venv 内含绝对路径）。
9. **卸载**：直接删除文件夹即可，无系统残留；索引数据全在包内 `data/`。
10. **故障排查入口**：`kb setup --check` 一键自检；`kb logs` 看日志；完整排查表见 `docs/安装与使用.md` 第 7 节。

## 9. 分享方信息（维护者看）

- 更新分享包：在 personal-kb 仓库 `git archive HEAD` + `fastembed_cache` + 本说明重打包（脚本见 lan-share 项目），用 `python3 share.py --file dist/personal-kb-share.zip` 服务（勿用默认 rebuild 流程，它不含模型缓存）。
- 分享服务是手动进程，机器重启后需重新启动；局域网 IP 变化后地址里的 IP 要跟着换。
